# Written report

`music-audience-analysis.pdf` is the completed academic report, including methods, detailed results, limitations, references and analytical dashboard previews. Presentation slides and video are not included.

The public CSV uses stable actor/comment labels. The historical report and some original figures retain the original reporting labels; these do not change the aggregate findings. The dashboard preview captions explicitly distinguish previews from Power BI Desktop screenshots.

The report provides detailed methods, results and interpretation supporting the repository overview.
